# Обезличенный каталог обращений

Из частного MD выделено 53 пересланных сообщений. Исходник и извлечённые персональные сведения остаются в закрытом локальном пространстве. Публичный casebook содержит только контролируемые ярлыки темы, обобщённую цель и вопросы для уточнения; фактические адреса, телефоны, имена, суммы, даты и исходные цитаты исключены. Автоматическая разметка тем предварительная и требует человеческой проверки перед оценкой качества по каждому случаю.

| GENERAL_APPEAL | 12 |
| SCHOOL_ENROLLMENT | 4 |
| OFFICIAL_CONDUCT | 4 |
| UNCLASSIFIED | 3 |
| SOCIAL_SUPPORT | 3 |

| BRIDGE_ROAD_SAFETY | 1 |

Четыре контролируемых сценария: отказ в зачислении ребёнка, спор о компенсации, запрос социальной помощи, опасный мост. В ответах бот просит нужные подробности и предлагает подготовить обращение; не обещает выплату, зачисление или решение и не назначает ведомство без территориального подтверждения. Файл `../casebook/appeal_cases_anonymized.jsonl` — каталог; `../runtime_export/appeal_scenarios.jsonl` — только безопасные реплики для runtime.
